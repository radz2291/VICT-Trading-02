# G3 fixtures

Identity-pinned fixture material for the G3 stage. All generators are
committed; regeneration is deterministic.

| File | What it is | Provenance |
|---|---|---|
| `hand-calculated-fixture.json` | 24-bar 15m XAUUSD-scale series + long/flat SMA3 strategy + hand-computed expected fills/equity/stats | generated by `gen-hand-calculated.mjs` from the hand table in its header comment (every fill, cost line, equity point derived on paper — see the table there) |
| `gen-hand-calculated.mjs` | the generator (single source of truth for the JSON) | run: `node gen-hand-calculated.mjs` |

## Reused pinned fixtures (from G2, unchanged)

- Poison-future baseline + alternate variants: `docs/evidence/G2/fixture/g2-fixture-baseline.json` / `g2-fixture-alternate.json` (seed 20260927, XAUUSD 15m, horizon at bar 1997, 25 poison bars after the horizon differing between variants; SHA-256s in `fixture-meta.json`).
- Gap behavior: the same series carries deliberate dropped slots (gap block `[300..307]` and singles `[17, 499, 1200]` in the base generator — `host/src/lib/fixture.ts`), exercised through R2's slot-complete aggregation.

## Consumers

- `packages/trading-kit/test/g3.test.mjs` — the kit suite (reads
  `hand-calculated-fixture.json` and asserts the runner reproduces the hand
  table exactly: fills with full cost math, equity curve, stats, SMA plot).
- `docs/evidence/G3/poison-proof.mjs` — criterion-7 proof (potency +
  isolation vs an independent clock-capped oracle at 15m/1h/4h).
- `docs/evidence/G3/selection/a2-engines/nt_eval.py` — the NautilusTrader
  local evaluation runs the SAME hand-calculated fixture through NT's engine.
