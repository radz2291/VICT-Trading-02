# Agent entry point

This repository hosts the VICT Trading Workspace — a chart-first personal trading application. All product and process documents live under [`docs/`](docs/README.md).

Before proposing or editing anything:

1. Read the development pack starting at [`docs/README.md`](docs/README.md), which gives the reading order, then [`docs/AGENTS.md`](docs/AGENTS.md).
2. Task authority comes only from a repository-specific, **accepted handoff**. A filled draft exists at [`docs/HANDOFF.md`](docs/HANDOFF.md) (status recorded in its header; template: [`docs/HANDOFF-TEMPLATE.md`](docs/HANDOFF-TEMPLATE.md)). Until that draft is accepted by the owner, no stage work is authorized.
3. If an instruction conflicts with the pack or the accepted handoff, stop and report the exact conflict; do not silently broaden scope.
