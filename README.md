# VICT Trading Workspace

A personal, chart-first trading workspace for one desktop trader. The chart is the home: the trader opens a bare XAUUSD or EURUSD chart and can freely draw, inspect, add indicators or scripts, rewind into history, test an idea, place simulated trades, and review outcomes — in any order, with no mandatory workflow blocking the way. VICT supplies governed boundaries for consequential operations; a specialized chart surface and external data/simulation components provide the domain machinery.

**Status: B0 (repository bootstrap) complete. G0 (technology intake and selection proof) has not begun.** No chart library, scripting runtime, simulation engine, data provider, or broker has been chosen. The pack under `docs/` is a proposed specification for owner review, not an independently verified program.
